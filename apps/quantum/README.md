# Source IRIS 
```
$ source ~/.iris/setup.source
```

# Install QIREE from https://code.ornl.gov/mach-q/qiree.  and use qiris.cqiree branch

# Set environment variable for QIREE CQiree shared library
```
$ export IRIS_LIB_QIREE=<path>/lib/libcqiree.so
```

# How to run
```
$ python3 test_qiree_renewed.py
```
